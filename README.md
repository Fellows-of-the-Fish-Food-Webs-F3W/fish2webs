# fish2webs

`fish2webs` is an R package for constructing size-structured aquatic food webs from fish survey data. The package provides a workflow to:

1. Extract, clean, and harmonise individual fish size measurements from ASPE surveys.
2. Build size-structured trophic metaweb based on species identity, ontogenetic diet shifts, and predator-prey size constraints.
3. Generate local food webs for individual sampling operations.
4. Compute structural and trophic metrics for local food webs.

The package builds on the companion packages:

- **fishdatabuilder**: tools for  extracting, cleaning, and processing fish survey data.
- **foodwebbuilder**: tools for constructing and analysing food webs.

---

# Installation

Install the package directly from GitHub using `pak`:

```r
install.packages("pak")
pak::pak("Fellows-of-the-Fish-Food-Webs-F3W/fish2webs")
library(fish2webs)
```

The required companion packages are installed automatically.

# Quick start

## Load trophic data

Load the trophic information required to construct the food webs:

```r
data(resource_diet_shift, package = "foodwebbuilder")
data(fish_diet_shift, package = "foodwebbuilder")
data(pred_win, package = "foodwebbuilder")
```

## Generate individual fish size and weight data and community- and species-level metrics
The first step is to extract, clean, and harmonise fish survey data from the ASPE database.
Individual fish sizes are then generated from the processed measurements, individual body weights are estimated from length-weight relationships, and richness, abundance, and biomass metrics are computed for each sampling operation, with abundance and biomass also provided at the species level.

```r
fish_individual_size <- fish2size(write_output = FALSE)
```

### Output objects

`fish2size()` returns a list containing five data frames:

| Object | Description |
|---|---|
| `site_information` | Sampling-site information, including site identifiers and geographic coordinates (longitude and latitude) |
| `operation_information` | Sampling-operation information, including operation and site identifiers, sampling date and time, fishing protocol, and sampled surface area |
| `species_information` | Fish species recorded in the dataset, with species codes and corresponding scientific names |
| `fish_individual_size_weight` | Individual fish records with operation and species identifiers, total body length, measurement status (measured or reconstructed), and body mass estimated from species-specific length–weight relationships |
| `community_metrics` | Operation-level fish species richness, abundance, and estimated biomass, provided as total values and standardized by sampled surface area |
| `species_level_metrics` | Species-level abundance and estimated biomass for each sampling operation, provided as total values and standardized by sampled surface area |

For example, the individual-level dataset used to construct the food webs can be accessed with:

```r
head(fish_individual_size$fish_individual_size_weight)
```

## Build food webs

`size2webs()` uses the individual fish data generated by `fish2size()` to construct a global size-structured metaweb and operation-specific local food webs.

### Example using a subset of operations

For demonstration purposes, local food webs can be generated for a limited number of sampling operations:

```r
selected_operations <- unique(
  fish_individual_size$fish_individual_size_weight$operation_id
)[1:100]

web_outputs <- size2webs(
  num_classes = 3,
  ind_measure = fish_individual_size$fish_individual_size_weight,
  resource_diet_shift = resource_diet_shift,
  fish_diet_shift = fish_diet_shift,
  pred_win = pred_win,
  write_output = FALSE,
  selected_operations = selected_operations
)
```

The global metaweb is constructed from the complete individual-level dataset. The `selected_operations` argument only restricts the local food webs that are generated.

### Full dataset

To generate local food webs for all sampling operations:

```r
web_outputs <- size2webs(
  num_classes = 9,
  ind_measure = fish_individual_size$fish_individual_size_weight,
  resource_diet_shift = resource_diet_shift,
  fish_diet_shift = fish_diet_shift,
  pred_win = pred_win,
  write_output = FALSE
)
```

Generating food webs for the complete dataset may require substantial computation time.

### Output objects

`size2webs()` returns a list containing:

| Object | Description |
|---|---|
| `trophic_species_size_classes` | Species-specific size-class boundaries defining trophic species |
| `metaweb` | Flattened representation of the global size-structured metaweb |
| `local_foodwebs` | Flattened representation of operation-specific local food webs |
| `local_foodweb_metrics` | Structural and trophic metrics computed for each local food web |

For example:

```r
head(web_outputs$local_foodweb_metrics)
```


# Examples
## Fish size distributions

Visualise individual body-size distributions for selected fish species.

```r
d <- 4

fish_data <- fish_individual_size$fish_individual_size_weight

unique_species_codes <- unique(
  fish_data$species_code
)

xlim <- range(
  fish_data$size_mm,
  na.rm = TRUE
)

par(
  mfrow = c(d, d),
  mar = c(3, 4, 2, 1),
  oma = c(2, 0, 2, 0)
)

for (i in seq_len(min(d^2, length(unique_species_codes)))) {

  species_code <- unique_species_codes[i]

  sizes <- fish_data$size_mm[
    fish_data$species_code == species_code
  ]

  hist(
    sizes,
    breaks = 20,
    xlim = xlim,
    col = "lightblue",
    border = "white",
    main = paste("Species:", species_code),
    xlab = "",
    ylab = "Count"
  )
}

mtext(
  "Fish size distributions by species",
  outer = TRUE,
  cex = 1.4
)

par(mfrow = c(1, 1))
```

## Analyse the global metaweb

The flattened global metaweb returned by `size2webs()` can be reconstructed as an adjacency matrix for further network analyses.

```r
metaweb <- unflatten_foodweb(
  web_outputs$metaweb
)
```

Compute structural and trophic properties of the global metaweb:

```r
basal_nodes <- get_basal_nodes(metaweb)
leaf_nodes <- get_leaf_nodes(metaweb)

degree_in <- compute_inward_degree(metaweb)
degree_out <- compute_outward_degree(metaweb)

TL <- compute_trophic_level(metaweb)

TB <- compute_trophic_breadth(
  metaweb,
  TL
)

fluxes <- compute_bottom_up_fluxes(metaweb)
```

Visualise the trophic structure of the global metaweb:

```r
plot_network(
  metaweb,
  x = TB,
  y = TL,
  labels = colnames(metaweb),
  xlab = "Trophic breadth",
  ylab = "Trophic level"
)
```

## Analyse a local food web

Select one sampling operation from the flattened local food-web table:

```r
local_foodwebs <- web_outputs$local_foodwebs

operation_id <- unique(
  local_foodwebs$operation_id
)[100]

local_foodweb_data <- local_foodwebs |>
  dplyr::filter(
    operation_id == !!operation_id
  ) |>
  dplyr::select(
    prey,
    consumer,
    interaction
  )
```

Reconstruct the corresponding local food web:

```r
local_foodweb <- unflatten_foodweb(
  local_foodweb_data
)
```


Compute structural and trophic properties:

```r
basal_nodes <- get_basal_nodes(local_foodweb)
leaf_nodes <- get_leaf_nodes(local_foodweb)

degree_in <- compute_inward_degree(local_foodweb)
degree_out <- compute_outward_degree(local_foodweb)

TL <- compute_trophic_level(local_foodweb)

TB <- compute_trophic_breadth(
  local_foodweb,
  TL
)

fluxes <- compute_bottom_up_fluxes(local_foodweb)
```

Visualise the local food web:

```r
plot_network(
  local_foodweb,
  x = TB,
  y = TL,
  labels = colnames(local_foodweb),
  xlab = "Trophic breadth",
  ylab = "Trophic level"
)
```

# Workflow summary

```text
ASPE surveys
      │
      ▼
fish2size()
      │
      ├── Site information
      ├── Sampling-operation information
      ├── Species information
      ├── Individual fish sizes and weights
      ├── Community-level metrics
      └── Species-level metrics
      │
      ▼
size2webs()
      │
      ├── Trophic-species size classes
      ├── Global metaweb
      ├── Local food webs
      └── Local food-web metrics
```
